# Seguimiento del Sprint 2

Este archivo se utiliza como un tablero sencillo para saber cuáles actividades faltan y cuáles ya se terminaron. Como el equipo solamente tiene dos integrantes, el estado se actualiza cuando alguno trabaja en el proyecto, sin necesidad de realizar una reunión diaria formal.

## Estados utilizados

- **Pendiente:** la actividad todavía no se ha iniciado.
- **En proceso:** la actividad tiene trabajo iniciado, pero aún requiere revisión.
- **Terminado:** el resultado está incorporado en el expediente y puede comprobarse mediante la evidencia indicada.

## Cómo se actualizará

1. Cuando alguien comience una actividad, cambiará su estado a **En proceso**.
2. Cuando el resultado esté incluido y revisado, se cambiará a **Terminado**.
3. Si cambia el alcance o una prioridad, se actualizarán los backlogs y las secciones relacionadas.
4. Los commits servirán para consultar los cambios realizados.

## Revisión de cierre

Antes de entregar, los dos integrantes revisarán que las actividades estén completas, que la información del README y del documento coincida y que cualquier pendiente quede anotado para el siguiente Sprint.
